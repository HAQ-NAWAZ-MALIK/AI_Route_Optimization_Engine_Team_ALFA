📋 Employees CSV Format

Upload a CSV file with employee pickup/drop locations.

Column Required Description
name or employee_name Optional Employee name
lat or latitude ✅ Yes Latitude coordinate
lng, lon, or longitude ✅ Yes Longitude coordinate
address or location Optional Address description
🚖 Cabs CSV Format

Upload a CSV file to define your vehicle fleet.

Column Required Description
name or vehicle_name Optional Vehicle identifier
capacity or seats Optional Passenger capacity (default: 4)
driver or driver_name Optional Assigned driver
🏢 Config CSV Format

Configure office location and trip settings. Two-column format: setting, value.

Setting Value Type Description
office_name Text Office name
office_lat Number Latitude (required)
office_lng Number Longitude (required)
office_address Text Street address
departure_time HH:MM Trip time
trip_type pickup/drop Route type
