POST /api/v1/optimize/route Optimization

Optimize a single route for one vehicle. Supports multiple algorithms, real-road routing, and traffic awareness.

Request Body

Parameter Description Required
origin Starting location (lat, lng, id) required
destinations Array of pickup locations required
constraints Time constraints {departureTime} required
options.algorithm auto | christofides | genetic | nearest_neighbor | dijkstra | bmssp optional
options.useRealRoads Use OSRM routing (default: true) optional
Example Request 
POST /api/v1/optimize/route
{
  "origin": { 
    "id": "office", 
    "lat": 34.05, 
    "lng": -118.24 
  },
  "destinations": [
    { 
      "id": "emp1", 
      "lat": 34.06, 
      "lng": -118.30 
    },
    { 
      "id": "emp2", 
      "lat": 34.08, 
      "lng": -118.28 
    }
  ],
  "constraints": { 
    "departureTime": "08:00" 
  },
  "options": { 
    "algorithm": "auto" 
  }
}
POST /api/v1/optimize/multi-cluster Optimization

Optimize routes for multiple vehicles simultaneously. Automatically clusters employees and balances cab loads.

Request Body

Parameter Description Required
office Office location (lat, lng, id) required
employees Array of all employee locations required
cabs Array of cabs with {id, capacity} required
config.routeOptimizationAlgorithm Algorithm for each route optional
Response 200 
{
  "success": true,
  "processingTimeMs": 245,
  "result": {
    "clusters": [
      { 
        "cabId": "cab1", 
        "employees": [...], 
        "route": {...} 
      },
      { 
        "cabId": "cab2", 
        "employees": [...], 
        "route": {...} 
      }
    ],
    "metrics": { 
      "totalDistance": 45.2, 
      "averageLoadFactor": 0.85 
    }
  }
}
POST /api/v1/matrix/distance Utilities

Calculate distance/duration matrix between all pairs of coordinates. Uses real road network by default.

Example Request 
{
  "coordinates": [
    { 
      "lat": 34.05, 
      "lng": -118.24 
    },

      "lat": 34.06, 
      "lng": -118.30 
    },
    { 
      "lat": 34.08,

  ],
