POST /v1/optimize Core

Route Optimization

The core endpoint. Send an origin, a list of destinations, and optional constraints — returns the most efficient route with distance, duration, and cost savings.

  • origin Starting coordinates {lat, lng} Required
  • destinations Array of destination coordinates Required
  • algorithm auto, nearest_neighbor, christofides, dijkstra, bmssp, greedy Optional
  • constraints Time windows, vehicle capacity, max stops Optional
optimize-route.ts 
// POST /v1/optimize
const response = await fetch("/v1/optimize", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    origin: { lat: 34.0522, lng: -118.2437 },
    destinations: [
      { lat: 34.0195, lng: -118.4912 },
      { lat: 34.0689, lng: -118.4452 },
      { lat: 33.9425, lng: -118.4081 }
    ],
    algorithm: "christofides",
    constraints: {
      departureTime: "08:00",
      maxDuration: 7200
    }
  })
});

const data = await response.json();
// → { optimizedRoute, totalDistance: "42.3km",
//     savings: "38%", duration: "47min" }
POST /v1/cluster Core

Multi-Vehicle Clustering

Automatically groups destinations into clusters based on geographic proximity and vehicle capacity. Assigns optimal vehicle routes for each cluster.

  • origin Fleet depot coordinates Required
  • destinations All employee/stop coordinates Required
  • vehicles Number of available vehicles Required
  • capacity Max passengers per vehicle Optional
cluster-fleet.ts 
// POST /v1/cluster
const result = await client.clusterDestinations({
  origin: { lat: 34.0522, lng: -118.2437 },
  destinations: employees,   // 150 employees
  vehicles: 5,
  capacity: 35
});

console.log(result.clusters);
// → [

//   { vehicleId: 3, stops: 31, route: [...] },
//   { vehicleId: 4, stops: 30, route: [...] },

console.log(result.totalSavings);
// → "42% reduction vs. unoptimized"
POST /v1/distance-matrix Utility

Distance Matrix

Computes the full NxN distance and duration matrix between all provided coordinates using the Haversine formula. Essential for pre-processing before optimization.

  • coordinates Array of {lat, lng} points Required
  • unit km or miles Optional
  • traffic Include real-time traffic data Optional
distance-matrix.ts 
// POST /v1/distance-matrix
const matrix = await client.distanceMatrix({
  coordinates: [
    { lat: 34.0522, lng: -118.2437 },
    { lat: 34.0195, lng: -118.4912 },
    { lat: 34.0689, lng: -118.4452 },
    { lat: 33.9425, lng: -118.4081 }
  ],
  unit: "km"
});

console.log(matrix.distances);
// → 4x4 matrix of pairwise distances
// [[0, 24.1, 18.7, 21.3],
//  [24.1, 0, 8.2, 12.6], ...]

console.log(matrix.durations);
// → 4x4 matrix of travel times (seconds)
GET /v1/geocode Utility

Geocoding

Convert street addresses into precise coordinates, or reverse-geocode coordinates back to human-readable addresses. Supports batch processing up to 100 addresses.

  • address Street address string One required
  • lat, lng Coordinates for reverse geocoding One required
  • batch Array of addresses (up to 100) Optional
geocode.ts 
// GET /v1/geocode — Forward
const geo = await client.geocode({
  address: "1600 Amphitheatre Pkwy, Mountain View"
});
// → { lat: 37.4220, lng: -122.0841,
//     formatted: "1600 Amphitheatre Parkway..." }

// GET /v1/geocode — Reverse
const addr = await client.geocode({
  lat: 37.4220,
  lng: -122.0841
});
// → { address: "1600 Amphitheatre Pkwy..." }

// Batch geocoding
const batch = await client.geocodeBatch({
  addresses: employeeAddresses  // up to 100
});
// → [{ lat, lng, formatted }, ...]
